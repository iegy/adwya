# أدوية مصر — ADWYA EGYPT

محرك بحث عربي/إنجليزي للأدوية المتداولة في مصر، مصمم كموقع Static/PWA سريع على GitHub Pages بدون Backend أو حسابات مستخدمين.

## المزايا
- قاعدة بيانات مصرية محلية داخل المستودع، تتم مزامنتها أسبوعيًا من مصدر CC0.
- بحث ذكي عربي/English بالاسم التجاري، المادة الفعالة، الشركة والتصنيف، مع تحمل الأخطاء الإملائية البسيطة.
- Web Worker للبحث حتى لا تتجمد الواجهة مع أكثر من 25 ألف مستحضر.
- صفحة تفاصيل لكل دواء داخل التطبيق مع رابط مشاركة مباشر.
- بدائل بنفس التركيب العلمي، مع أولوية لطريق الاستخدام والتركيز الظاهر من اسم المستحضر.
- مقارنة حتى 4 أدوية ومفضلة محلية بدون تسجيل.
- تصفح المواد الفعالة والشركات والتصنيفات.
- سجل لتغييرات الأسعار التي يرصدها نظام المزامنة من لحظة تشغيله.
- زر للتحقق من مصادر هيئة الدواء المصرية، وروابط للقوائم الدورية الرسمية.
- الإبلاغ عن سعر غير صحيح عبر GitHub Issue مُعبأ تلقائيًا.
- Light/Dark، RTL، دعم الموبايل، PWA وOffline cache.
- مولد SEO ينشئ صفحات Static لكل دواء ولكل مادة فعالة وشركة وتصنيف، مع sitemap.xml وStructured Data.

## مصادر البيانات
- Egyptian Drug Database: https://github.com/karem505/egyptian-drug-database — CC0-1.0 — آخر تحديث معلن يونيو 2026.
- Egyptian Drug Authority (EDA): EDDB والقوائم الدورية الرسمية للتحقق التنظيمي.

> **تنبيه طبي:** الموقع معلوماتي فقط. لا يصف جرعات، لا يشخّص، ولا يقرر الاستبدال العلاجي. السعر والتوافر قد يتغيران ويجب التحقق منهما وقت الشراء.

## النشر على GitHub Pages
الموقع يعمل مباشرة من جذر `main`. للنشر الكامل مع صفحات SEO المولدة:
1. من Settings → Pages اختر **GitHub Actions** كمصدر النشر.
2. شغّل Workflow باسم **Build & deploy ADWYA EGYPT** مرة واحدة.
3. بعد أي تحديث كبير للبيانات يمكن تشغيله مرة أخرى. المزامنة الأسبوعية للبيانات مستقلة.

## التطوير محليًا
شغّل Static Server من جذر المشروع، مثل:
```bash
python -m http.server 8080
```
ثم افتح `http://localhost:8080`.

## الخصوصية
لا توجد حسابات ولا Analytics في النسخة الحالية. المفضلة واللغة والثيم محفوظة في Local Storage، وملفات الموقع/البيانات قد تُخزن في Cache Storage للعمل الأسرع أو دون اتصال.
