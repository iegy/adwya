# أدوية مصر — ADWYA EGYPT

محرك بحث عربي/إنجليزي للأدوية المتداولة في مصر، يعمل كموقع Static/PWA على GitHub Pages بدون Backend.

## النسخة الحالية
- بحث ذكي بالعربي والإنجليزي بالاسم التجاري، المادة الفعالة، الشركة والتصنيف.
- تطبيع عربي لتجاهل التشكيل والهمزات والاختلافات الشائعة.
- بدائل بنفس المادة الفعالة مع ترتيب بالسعر.
- مقارنة أدوية وحفظ المفضلة محليًا.
- دعم Light/Dark وRTL وموبايل.
- PWA + Cache محلي لقاعدة البيانات بعد أول تحميل.
- مصدر البيانات الحالي: Egyptian Drug Database (CC0)، آخر تحديث معلن يونيو 2026.

> الموقع معلوماتي ولا يصف جرعات ولا يستبدل الطبيب أو الصيدلي. السعر قد يتغير ويجب التحقق منه عند الشراء.

## تشغيل محلي
افتح المشروع عبر أي static server (مثل `python -m http.server 8080`) ثم افتح `http://localhost:8080`.

## النشر
المشروع مصمم ليعمل مباشرة من GitHub Pages من جذر فرع `main`.
